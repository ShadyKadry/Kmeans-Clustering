Comparing clustering results

To compare two clustering assignments, we can use the Adjusted Rand Index (ARI) that corrects the simple Rand Index by subtracting the expected similarity of random clusterings and normalizing the result. With this we can check how similar two clustering results are.

Example

We will start by running two different K-means clusterings, e.g. the Simple KMeans algorithm and the K-Medoids algorithm.

    using KMeansClustering

    X = rand(2, 200)
    cluster_count = 10

    simple_clustering_result =
        KMeansClustering.kmeans(
            KMeansClustering.SimpleKMeansAlgorithm(X, cluster_count; init_method=:random)
        )
    kmed_clustering_result =
        KMeansClustering.kmeans(
            KMeansClustering.KMedoidsAlgorithm(X, cluster_count)
        )
KMeansResult{Float64, Matrix{Float64}}([0.046795933912257996 0.6267730790260252 … 0.19349558170529793 0.6579695267611088; 0.2770414105450352 0.06518572089418402 … 0.596998262655771 0.17221068540581727], [1, 4, 6, 8, 5, 6, 4, 9, 9, 5  …  9, 1, 7, 7, 5, 4, 8, 5, 2, 9], 7378.504364963719, 1, true, :random)

Now we will use our helper function to check our two clusterings for similarity by comparing the assignment vectors of both results.

    label_km = simple_clustering_result.assignments
    label_kmed = kmed_clustering_result.assignments

    adjusted_rand_index(label_km, label_kmed)
0.6017080798982751

The closer the ARI is to 1 the better do the two clusterings match. Note that this does not say anything about cluster quality itself. For this we could check the intertia.

    println("Inertia of Simple Kmeans result: ", simple_clustering_result.inertia)
    println("Inertia of K-Medoids result: ", kmed_clustering_result.inertia)
Inertia of Simple Kmeans result: 3.8201579865517497
Inertia of K-Medoids result: 4.356291441059138

Smaller inertia stands for better cluster quality.
